# Conspectus

*Conspectus* (Latin): a view of the whole; a survey of everything at once.

A side project, built slowly and in an agile way. This file holds the vision as Tural described it on 2026-10-25, in his own words. Nothing here is a plan yet.

## The idea

> "The world is kind of going to shit — wars popping up and a lot of stuff that I probably don't know about … protests now are starting in a lot of countries."

> "A web page … there could be AI agents running in the background tracking news constantly and then updating an interactive world map that basically shows what's going on, and linking everything to each other."

> "Somebody could go in and be like: oh, there are protests going on here, this war is going on like this, oh now this guy is involved in this war."

## A high-level view, not a battle map

> "I'm not going to be drawing borders and pointing out specific battlegrounds … I want more of a high-level global view of what's happening around the world, politics-wise."

> "This is a place where you can see, you have visibility … it's like an eagle's view. It's like you're stepped outside of the world, you're an astronaut looking at the world."

## Map and graph

> "Maybe if we could somehow have a map and graph view, or if we could smoothly integrate that kind of thing, it would be amazing."

His example of how involvement changes with events:

> "Let's say Iran and the US are in war, and now Iran bombed a random country somewhere in the Arabian Peninsula, but they haven't responded. So maybe they're involved — they're involuntarily involved. And then if they say 'oh no, we don't care, it was a mistake', then they're not involved. Or if they say 'now you got it, Iran, we are now involved' — they're involved."

## Malleable

> "I would preferably like the system to be malleable … I don't want to have to consider each and every kind of possible scenario. I want the agents to be able to put stuff in that maybe it's the first time something like this is being seen."

## Open

> "Regarding AI doing the reading, we'll see … we'll experiment."

How the agents read the news, what the map shows and how it looks are still to be decided.
